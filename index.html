Toca una unidad azul para seleccionarla y toca el mapa para moverla. Elige una carta y toca tu territorio para desplegar. Toca una trinchera para entrar; dentro, doble toque en el terreno para salir. Arrastra para seleccionar varias unidades (si no hay ninguna dentro, se suelta la selección); doble toque en una unidad selecciona todas.
